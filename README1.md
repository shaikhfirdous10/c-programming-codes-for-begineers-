rules of constructing constants:
Rules for constructing integer constants:
1. Must contain at least one digit.
2. Cannot contain a decimal point.
3. Cannot contain commas or blank spaces.
4. Can be positive or negative.
5. Cannot contain alphabetic characters (except suffixes like U, L).
6. Leading zeros indicate octal numbers (base 8).
7. Prefix 0x or 0X indicates hexadecimal numbers (base 16).

2. Real (Floating-Point) Constants
Real constants are numbers that contain a fractional part or are written in exponential notation.

Rules for constructing real constants:
1. Must contain a decimal point or an exponent (or both).
2. Can be positive or negative.
3. Must not contain commas or blank spaces.
4. Exponent must be followed by a valid integer.


3. Character Constants
Character constants represent a single character enclosed within single quotation marks.

Rules for constructing character constants:
1. Must be enclosed within single quotes (' ').
2. Normally contain one character.
3. Can contain escape sequences.
4. Cannot contain multiple ordinary characters.
5. Character constants are of type int in C.
